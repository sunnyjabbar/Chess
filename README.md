# ♟️ JavaScript Chess Game

A browser-based chess game built using **HTML, CSS and JavaScript**. The project provides an interactive chessboard where two players can play against each other, make legal moves and track the progress of their game.

## About the Project

This project was created to develop my web development and JavaScript programming skills. It uses the chess.js library to manage chess rules and validate moves, while HTML and CSS provide the interface and styling.      

The game runs directly in a web browser without requiring any additional software.

## Features

- **Interactive Chessboard** – Select pieces and move them to highlighted legal squares.
- **Legal Move Validation** – Prevents players from making illegal chess moves.
- **Move History** – Displays previous moves throughout the game.
- **Captured Pieces** – Keeps track of pieces captured by each player.
- **Check and Checkmate Detection** – Identifies check, checkmate and the winning player.
- **Draw Detection** – Recognises stalemate, insufficient material and other draw conditions.
- **Pawn Promotion** – Allows pawns reaching the opposite end of the board to promote to a queen, rook, bishop or knight.
- **Undo Move** – Allows players to take back their previous move.
- **Flip Board** – Changes the board orientation.
- **New Game** – Starts a fresh chess match.
- **Draw Claims** – Allows players to claim a draw when eligible.

## How to Run the Game

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or open the html file and it will open in your browser.
3. Open `chess.html`.
4. Run the file
5. The chess game will open in your web browser.

## External Library

This project uses [chess.js](https://github.com/jhlywa/chess.js), version 0.10.3, to handle chess rules and move validation.
